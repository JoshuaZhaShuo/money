# 合账 · 微信支付宝记账

手机记账 PWA，支持微信/支付宝合并流水、手动记账、统计、账户详情，以及 iPhone 快捷指令 OCR 导入。

## 在 iPhone 上使用

用 Safari 打开 https://joshuazhashuo.github.io/money/，点击分享 → 添加到主屏幕，即可像 App 一样独立打开。

## iPhone 快捷指令

1. 截取屏幕
2. 从图像中提取文本
3. URL 编码文本
4. 打开 https://joshuazhashuo.github.io/money/?ocr=识别文本
5. 将快捷指令绑定到“轻点背面”

账单目前保存在当前设备浏览器本地，不会上传到服务器。
